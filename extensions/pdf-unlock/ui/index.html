PDF Unlock

Re-prints encrypted PDFs through the system print-to-PDF engine and replaces the originals in place.

    How this works

    Each page is redrawn into a brand-new PDF. The new document is authored from scratch, so it carries no encryption dictionary and no permission flags. Text stays selectable vector text; it is not rasterized.

    Because the page is re-printed, interactive extras do not survive: links, bookmarks, form fields, annotations and attachments are dropped. Pick the lossless qpdf engine if you need to keep them.

    The original is only replaced after the new file is verified to be unencrypted and to have the same page count, and the swap is an atomic rename on the same volume.

    A PDF that needs a password just to open cannot be unlocked without that password — enter it above.
