Daily spend (USD), with every automation overlaid on the same graph. Follows all filters. Hover, tap or use ← → to read a day; select a legend entry to highlight its line without hiding the others.

Only captured usage is shown, linked through local automation run records. Includes all spend in linked run sessions, including later work in the same session. Session-level totals use the day the session reported or started. Unlinked automation sessions are shown separately; zero means no recorded spend under these filters.

1 AI credit = 1 AIU = $0.01. Months are UTC (as GitHub bills); the hour-of-week grid uses your local time zone. Built on this computer from your local Copilot telemetry; nothing leaves it, and no prompts, session titles or file paths are read.
