RPP repair
Manual path replacement
Review each missing reference and candidate. Preflight checks the Reaper process, project hash, watcher, candidate readability/stat, destination writability, disk space and backup integrity. Confirm every old path → new path. Bridge creates and SHA-verifies a manifest-backed backup, writes atomically, rescans, and reports remaining missing refs.
Portable RPP export
Project plus source media
Available only for Reaper in this workflow. It copies and SHA-verifies source audio into a separate package. It does not include plugin libraries or create a cross-DAW conversion. Close Reaper before export.
WAV analysis
Technical report only
PCM WAV 8/16/24/32-bit, up to 30 minutes. Peak/RMS/crest and sampled spectral metrics are not LUFS, true-peak, mastering advice, or a substitute for listening.
Honest limitations: no plugin rendering; no full cross-DAW conversion; no machine-learning model, source separation, or mastering certification. CPR/LOGICX/SONG are read-only partial/heuristic adapters; missing fields do not prove absence. Routing/plugin hints are not compatibility checks.
