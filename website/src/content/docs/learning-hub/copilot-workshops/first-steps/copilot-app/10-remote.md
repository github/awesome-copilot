This lesson is optional, and worth saving until the local loop feels natural. The `/remote` command keeps the session running locally while making it available on the web and in the GitHub Copilot mobile app. Your machine needs to stay on while you follow the session from another device.

In this lesson, you will:

- make an in-progress session available remotely.
- follow the session from your browser or the GitHub Copilot mobile app.
- review the resulting changes like any other pull request.

## Continue a session remotely

1. Open a session that has work in progress.
2. Run `/remote` to make that session available remotely.
3. Open the link it returns in your browser, or access the session in the GitHub Copilot mobile app.
4. Follow its progress from there, then review the changes exactly as you would any other pull request.

> [!NOTE]
> **This is not delegation**
>
> The session still runs on your machine. You are not handing the task to a different agent or moving it to the cloud.
