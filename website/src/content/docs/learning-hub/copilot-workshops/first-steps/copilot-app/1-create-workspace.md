Create a local workspace for the Space Quiz and configure a session that keeps you in control as the agent begins working.

In this lesson, you will:

- open an empty local folder.
- start an Interactive agent session.
- confirm the folder, mode, and model before the first prompt.

## Create the workspace

1. Open the GitHub Copilot app and confirm that you are signed in.
2. Select **New**, then **Open folder**, and choose an empty folder named `space-quiz`. Create the folder first if it does not exist.
3. Set the session mode to **Interactive**.
4. Choose your preferred model using the [preference order from Lesson 0][model-order].
5. Select **Create**. The session opens empty and waits for your first prompt.

![Illustration of the Copilot app New screen with a prompt box, the Interactive mode, Auto model, and Default agent pickers, and the space-quiz folder on the Local main branch.](/images/learning-hub/copilot-workshops/first-steps-app-new-session.svg)

The **New** screen is where you set the folder, the mode, and the agent before you type the first prompt. An Interactive session lets you direct the work and review each stage while the agent builds the project.

## Summary and next steps

Your empty Space Quiz workspace is ready. Continue to [Lesson 2: Build and polish the quiz][next-lesson].
