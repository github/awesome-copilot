Take a beginner-friendly, hands-on tour of GitHub Copilot in Visual Studio Code. You will build a colorful Space Quiz from an empty folder and learn the editor loop: build in a workspace, inspect context, test before Git writes anything, plan before you edit, and let GitHub tools handle issues and pull requests without leaving VS Code.

The workshop takes approximately 60 to 90 minutes. Your project uses a single HTML file with no runtime dependencies, so you can focus on learning Copilot in the editor.

> [!NOTE]
> This workshop was created by [James Montemagno][james] and adapted from [First Steps with GitHub Copilot][source-lab]. The original content is available under the [MIT License][source-license].

## Lessons

| Lesson | Topic | What you will do |
| ------ | ----- | ---------------- |
| [0. Prerequisites and setup][lesson-0] | Setup | Verify prerequisites, add the GitHub extension, open a folder, and choose a model |
| [1. Build in the workspace][lesson-1] | Build | Build the quiz, preview it in the integrated browser, and polish an element you pick |
| [2. Capture project instructions][lesson-2] | Instructions | Generate and tailor `.github/copilot-instructions.md` with `/init` |
| [3. Inspect context and test][lesson-3] | Test | Inspect chat context and run a smoke test before Git writes anything |
| [4. Publish the project][lesson-4] | Publish | Initialize, commit, and publish with Source Control |
| [5. Plan before you edit][lesson-5] | Plan | Use Plan mode to agree on an approach for the next feature |
| [6. Give Copilot GitHub-aware tools][lesson-6] | Tools | Enable and review the GitHub MCP server |
| [7. Plan and implement issues][lesson-7] | Implement | Create issues with GitHub tools and implement one in a new session |
| [8. Review and merge][lesson-8] | Review | Create a pull request from Source Control, request a review, and merge |
| [9. Hand off to a cloud session][lesson-9] | Delegate | Switch the harness to Cloud and delegate a new feature |
| [10. Review and next steps][lesson-10] | Review | Recap the workflow and continue learning |
