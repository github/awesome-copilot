セッションで実際に作業を行ったので、確認する内容ができました。エージェントがどこを作業対象にしているかを確認し、その後、統合ブラウザーでクイズを操作してもらいます。意図したことではなく、実際に起きたことを報告してもらいましょう。

このレッスンでは、次の内容を学習します。

- タイトルメニューでプロジェクトとセッションのコントロールを確認する。
- 使用状況メニューでプラン、セッションの使用状況、トークン、コンテキストを確認する。
- ブラウザーレベルのスモークテストを実行し、問題があれば修正する。

## プロジェクトの詳細を確認する

タイトルバーの **Build a space quiz** を選択して、プロジェクトとセッションのメニューを開きます。

![Build a space quiz タイトルメニューの図。space-quiz プロジェクトのフォルダーセッションを示し、パス、リモート操作、名前、ネストされたセッション、セッション ID、共有、アーカイブ、削除のコントロールが表示されています。](/images/learning-hub/copilot-workshops/first-steps-app-project-details.svg)

このメニューは、セッションが作業しているプロジェクトを示し、セッションを管理するためのコントロールを提供します。

1. フォルダーセッションが `space-quiz` プロジェクト用であることを確認します。
2. **Path** を選択し、セッションが意図したフォルダーで作業していることを確認します。
3. リモート操作、名前の変更、ネストされたセッション、共有、アーカイブ、削除のコントロールを確認します。

## 使用状況の詳細を確認する

**Send** の横にある使用状況コントロールを選択して、プランとセッションの使用状況メニューを開きます。

![Send ボタンの横にある使用状況メニューの図。GitHub Copilot Pro+ プラン、セッションの AI クレジット、入力トークン数と出力トークン数、40 万トークンのうち 16 パーセントのコンテキスト使用率が表示されています。](/images/learning-hub/copilot-workshops/first-steps-app-usage-details.svg)

このメニューでは、アカウントとセッションの使用状況がプロジェクトのコントロールから分けて表示されます。

- **Plan** には、情報が利用可能な場合にプランレベルの使用状況が表示されます。
- **Session** には、現在のセッションで使用した AI クレジットが表示されます。
- **Tokens** には、入力、キャッシュ済み、出力、推論のトークン数が表示されます。
- **Context** には、セッションがコンテキストウィンドウをどれだけ使用したかが表示されます。

セッションが進むにつれて **Context** を確認します。コンテキストが埋まるほど、実際のタスクに使える余地が少なくなります。これは新しいセッションを始める目安です。

> [!TIP]
> **望ましくない結果の多くはコンテキストの問題です**
>
> 間違ったフォルダーや、ほぼ満杯のコンテキストウィンドウは、よくないプロンプトよりもはるかに多くの予想外の結果の原因になります。

## Git に変更を記録する前にテストする

統合ブラウザーは実際のブラウザーなので、エージェントがクイズを操作して動作を検証できます。次のプロンプトを送信します。

```plaintext
Run a browser-level smoke test for the quiz in the integrated browser. Check keyboard navigation, score updates, correct and incorrect feedback, and the results screen. Fix any failures, then report what passed.
```

1. エージェントが質問に回答していく様子を統合ブラウザーで確認します。
2. 何か失敗した場合は、すべて合格するまで、エージェントに修正とテストの再実行をしてもらいます。
3. ビルドとテストが成功してから次に進みます。

まだ Git には何も記録していません。次のレッスンでは `/init create simple rules for the project` を実行します。現状のプロジェクトを読み取るため、先にプロジェクトが動作することを確認しておく価値があります。
