让 Copilot 创建议题或处理拉取请求*之前*，先启用 GitHub MCP 服务器。有了这些工具，Copilot 就能直接从聊天中读取和写入 GitHub 数据。

本课将：

- 启用 GitHub MCP 服务器。
- 审查服务器请求的工具和权限。
- 确认聊天中可以使用 GitHub 工具。

## 启用 GitHub MCP

1. 打开 VS Code **Settings**，如果当前版本包含内置的 **GitHub MCP** 服务器，就启用它。
2. 否则，通过 [MCP 服务器配置流程][mcp-servers]安装可信的 GitHub MCP 服务器。
3. 批准之前，审查服务器请求的工具和权限。
4. 确认 GitHub 工具出现在 Copilot Chat 的工具选择器中。

## 总结与后续步骤

Copilot 现在具备了可操作 GitHub 的工具。继续学习[第 7 课：规划并实现议题][next-lesson]。
