完成开发流程，无需切换到桌面界面。

本课将：

- 最后检查一次已更改的文件。
- 从当前分支创建拉取请求。
- 审查拉取请求并处理反馈。
- 使用 `/pr agentmerge` 验证并合并拉取请求。

## 创建、审查与合并

1. 运行 `/diff`，最后检查一次已更改的文件。
2. 让 Copilot 从当前分支创建拉取请求，或运行 `/pr create`。
3. 打开侧面板的 **Pull requests** 选项卡，检查标题、描述、文件和状态检查。
4. 处理可执行的反馈，在浏览器中检查结果，并回复更改内容。
5. 拉取请求准备就绪后，运行 `/pr agentmerge`，让它验证拉取请求，并在完成所需确认且检查通过后合并。
