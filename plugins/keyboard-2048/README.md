# Keyboard 2048 Canvas

Play 2048 in a Copilot canvas with keyboard and touch controls, undo, and session saves.

## Installation

```bash
copilot plugin install keyboard-2048@awesome-copilot
```

## Development

From `extensions/keyboard-2048`, run the lifecycle, game, and server tests with Node.js 22.15 or later:

```bash
node --test extension.test.mjs game.test.mjs server.test.mjs
```
