# PR Review Plugin

Review GitHub pull requests in a read-only canvas. Copilot groups related
changed files from their paths and metadata, displays complete expandable
diffs, and answers questions scoped to a group, file, or hunk. Review snapshots
and answers stay in the current session.

## Installation

```bash
copilot plugin install pr-review@awesome-copilot
```
