# The Daily Letdown

A date-aware GitHub Copilot canvas calendar with an original demotivational line for every month and day, including leap day. Browse dates with the arrows or date picker, jump back to today, and switch between light and dark themes. It works offline and has no runtime dependencies.

## Installation

```bash
copilot plugin install demotivational-calendar@awesome-copilot
```
