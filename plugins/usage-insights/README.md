# Usage Insights Plugin

Inspect current and historical GitHub Copilot token and AI-credit usage with
per-agent rollups and in-canvas session drill-down.

## Installation

```bash
copilot plugin install usage-insights@awesome-copilot
```

## Features

- Live input, output, reasoning, cache, and AI-credit metrics
- Root-agent and sub-agent usage rollups
- Model-call counts, durations, and cumulative usage timeline
- Local session history with in-canvas drill-down
- Read-only local data access with no external telemetry

## Privacy

The marketplace preview contains only synthetic sample data and generic session
and agent names.
