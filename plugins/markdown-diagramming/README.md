# Markdown Diagramming

A modular toolkit for designing and generating architecture diagrams in Markdown.

## Installation

```bash
copilot plugin install markdown-diagramming@awesome-copilot
```

## What's Included

- **C4 Architecture Modeling** (`c4-architecture-modeling`): choose and model
  focused C4 views, document relationships, and record evidence and assumptions.
- **Mermaid Markdown Diagrams** (`mermaid-markdown-diagrams`): render supplied
  models as Markdown Mermaid diagrams and validate syntax when a local renderer
  is available.

Use either skill on its own. For a combined workflow, model the architecture
with the C4 skill, then use the Mermaid skill to render the selected view. The
plugin packages both skills but does not impose an automatic execution order.
