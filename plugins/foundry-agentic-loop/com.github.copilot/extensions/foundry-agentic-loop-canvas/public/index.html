      Pick a prompt template on Start to launch the workflow. This tab follows it live: each phase, its agents, the evidence it writes and the gate it must pass.

      1. 1

        Specify

        EARS acceptance criteria, a frozen contract, workstreams and a deployment plan, checked by an independent reviewer.

        Gate · you approve the spec and plan

      2. 2

        Implement

        azd provisions the Foundry project and a hosted checkpoint proves the integration before agents, tools and app are built in parallel.

        Gate · provisioned, checkpoint proven, tests pass

      3. 3

        Verify

        Every acceptance criterion tested end to end, plus hosted invocations, traces and agent evaluations, with bounded fix loops.

        Gate · criteria, evaluations and traces pass, or you decide

      4. 4

        Deploy

        azd up ships agents and apps with keyless auth and monitoring, then reruns the end-to-end tests against the deployed endpoints.

        Gate · you approve before azd up
