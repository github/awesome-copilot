# Azure DevOps Team load

Browse selected people's open Azure Boards work items, authored active Azure Repos PRs, outstanding individual reviews and unassigned work needing an owner.

The canvas uses the signed-in Azure CLI identity and selected Azure DevOps Services organisations/projects. There are no seeded organisations or people, remote writes, Teams presence, hour estimates or agent-running claims.

See the [extension guide](../../extensions/ado-personal-team-load/README.md) for installation, exact authentication commands, scope selection, counting rules, coverage boundaries and independent live-count verification.

## Included extension

1. `ado-personal-team-load`, reusable source in `extensions/ado-personal-team-load`.
2. Canvas ID: `ado-personal-team-load`.
3. Private profiles under the resolved Copilot home's `extension-data/ado-personal-team-load`.

The preview is a genuine unconfigured canvas. It contains no customer work, organisation names or identities.
