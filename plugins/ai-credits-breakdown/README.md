# AI Credits Breakdown Plugin

See exactly where your own GitHub Copilot AI credits go: dollars by day, repository, model, call type and prompt-cache state, built privately on your computer from your Copilot telemetry.

## Requirements

- GitHub Copilot app with canvas support
- Node 22.13+ (the extension uses `node:sqlite` and will not load on older Node versions)

## Installation

```bash
copilot plugin install ai-credits-breakdown@awesome-copilot
```

## Source

This plugin is part of [Awesome Copilot](https://github.com/github/awesome-copilot). See the [extension README](../../extensions/ai-credits-breakdown/README.md) for what it shows and exactly what it reads.
