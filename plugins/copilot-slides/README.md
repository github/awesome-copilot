# Copilot Slides Plugin

Create, edit, present and export local slide decks in a Copilot canvas. Copilot builds decks from your notes and files, you refine them by hand, and everything stays on your machine.

## Installation

```bash
copilot plugin install copilot-slides@awesome-copilot
```

## What you get

- A slide editor canvas with text, shapes, images, tables and charts, speaker notes and comments.
- Revision-safe collaboration: Copilot reads a deck with `get_deck` and saves with the version it read, so it never overwrites your newer edits.
- Presentation and presenter views, plus HTML, PNG, PDF (print), editable JSON and PowerPoint export, and PowerPoint import.
- An English and Japanese interface. It follows the browser or app language; pass `locale` when opening the canvas to force one.

See the [extension README](../../extensions/copilot-slides/README.md) for the full feature list, the privacy model and the available actions.
