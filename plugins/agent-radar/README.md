# Agent Radar Plugin

See a live map of the Copilot agents on your computer, their sub-agents, their commands, and where their data goes.

## Requirements

- GitHub Copilot app with canvas support

## Installation

```bash
copilot plugin install agent-radar@awesome-copilot
```
