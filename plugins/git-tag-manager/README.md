# Git Tag Manager Plugin

Manage local and remote Git tags, create and push release tags, and delete tags with confirmation.

## Installation

Once published to Awesome Copilot:

```bash
copilot plugin install git-tag-manager@awesome-copilot
```

To install directly from the shared extension URL, ask Copilot:

```text
Install this extension: https://github.com/github/awesome-copilot/tree/main/extensions/git-tag-manager
```

## Source

This plugin is part of [Awesome Copilot](https://github.com/github/awesome-copilot). It ships the reusable [Git Tag Manager extension](../../extensions/git-tag-manager/README.md), which documents usage, canvas actions, storage, and validation.
