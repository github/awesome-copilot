# Optional shared knowledge base

Private project context holds working detail. A shared knowledge base holds durable cross-project synthesis under its own ownership and publication rules. Each claim has one authoritative home; related pages update their applicability and links rather than becoming competing sources of truth. A shared knowledge base is not a copy of the private folder.

1. Resolve the existing project identity mapping, approved destination and owning workflow. Read its current rules. If no such system is configured, this mode is N/A; the local workflow remains usable without another skill, product or service.
2. Follow claim IDs, citations, backlinks and current primary sources to materially related pages. Reconcile affected maintained pages only within current authorization. A permitted project page does not grant access to adjacent policy or organization-wide collections.
3. Complete authorized updates and readback. Otherwise prepare exact target/diff proposals and record pending authority. Protected policies require their owner's exact approval; use existing valid approval without asking again. Do not edit immutable policy sources. Keep draft, observed and open claims distinct from accepted facts, and proposals outside trusted retrieval under the owner's exclusion/labeling rules.
4. Apply the owner's schema/link/log/validation requirements only to actual changes. Reindex only changed indexed sources or a confirmed stale-index defect; verify a scoped lookup and source revision afterwards. A local instruction edit does not imply a knowledge-base indexing job. No-op creates no date, log or indexing churn.
5. Report saved, indexed and discoverable states separately for each consumer. This skill does not alter repository sync policies or authorize commit/push, messages or external publication.

If the shared service is unavailable, finish independent local updates and retain exact pending destinations with their evidence. Persistent user memory is not a substitute. A private proposal has not yet reached the shared system.
