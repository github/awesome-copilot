# BulkPublish Social Media

Use this skill when an AI agent needs to manage a social-media content workflow across connected channels with BulkPublish.

## Workflow

1. Confirm audience, objective, platform, voice, timing, and approval requirements.
2. Draft and adapt content for each platform, checking accessibility, disclosures, and factual accuracy.
3. Prepare a BulkPublish draft and show the intended change before scheduling or publishing.
4. Schedule or publish only after explicit authorization.
5. Verify the BulkPublish result, then use its analytics to report performance and plan the next iteration.

## Safety

- Treat publishing, scheduling, edits, deletions, and channel changes as externally visible mutations.
- Never expose API keys or claim success without checking the returned BulkPublish state.
- Prefer drafts and previews when requirements or approval status are unclear.
