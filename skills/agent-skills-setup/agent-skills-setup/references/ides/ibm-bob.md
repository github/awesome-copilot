# ibm-bob

IBM Bob provides IDE and Bob Shell profiles. Skills are supported in `.bob/skills` and `~/.bob/skills`. Rules include `.bob/rules`, mode-specific rules, and `AGENTS.md`. IDE global MCP is `~/.bob/mcp.json`, Bob Shell MCP is `~/.bob/mcp_settings.json`, and project MCP is `.bob/mcp.json`.

Sources: [docs](https://www.ibm.com/products/bob).
