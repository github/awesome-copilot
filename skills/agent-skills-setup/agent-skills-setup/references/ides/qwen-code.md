# qwen-code

Qwen Code uses `~/.qwen/skills/` and `.qwen/skills/` for user and project Skills. MCP is the `mcpServers` subobject in `~/.qwen/settings.json` or `.qwen/settings.json`; HTTP uses `httpUrl`, while legacy SSE uses `url`.

Preserve Qwen-only Skill activation metadata through the loss report. Never migrate OAuth token stores or automatically generated/archived Skills as hand-authored content.

Sources: [Skills](https://github.com/QwenLM/qwen-code/blob/main/docs/users/features/skills.md), [MCP](https://github.com/QwenLM/qwen-code/blob/main/docs/users/features/mcp.md).
