# warp-oz

Oz is Warp's current local/cloud agent CLI; `warp-cli` is deprecated. Skills, MCP, and agent profiles are run-level or cloud-managed inputs exposed by `--skill`, `--mcp`, and `--profile` rather than one portable local directory contract.

Generate a reconstruction plan and exact CLI arguments. Do not copy Warp Drive rules, saved prompts, notebooks, workflows, API keys, or cloud profile state.

Source: [Oz CLI](https://docs.warp.dev/reference/cli).
