# gitlab-duo

GitLab Duo Agent Platform provides VS Code, JetBrains, CLI, Web, and Flow surfaces. User-level AGENTS are located at `~/.gitlab/duo/AGENTS.md` (Linux/macOS) or `%APPDATA%\GitLab\duo\AGENTS.md` (Windows). Project and subdirectory AGENTS hierarchy is respected.

Sources: [docs](https://docs.gitlab.com/ee/user/duo_agent_platform/).
