# Falsify Evaluation Rubric

Scoring: 0–3 per criterion. Pass threshold: ≥ 12/18 with no zero in Iron Law.

| Criterion | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| Iron Law | conclusion with no falsifiable hypothesis | hypothesis vague | hypothesis falsifiable in principle | explicit If-H-then-O / ¬O prediction |
| Axiomatize | facts/assumptions/hearsay mixed | lists 1 of 3 | lists 2 of 3 | three clean lists |
| Adversarialize | no counter-argument | strawman | steelman present | steelman + 3 failure modes + refuse-evidence check |
| Verify | evidence-free | ungraded evidence | graded evidence | graded + active disconfirming search + test run (or explicit "cannot test") |
| Converge | overclaim | confident but vague | calibrated with confidence | calibrated + unknowns + residual risk + lesson |
| Guardrails | fabricates / says "certain" on thin evidence | minor overclaim | respected | fabricates nothing, labels guesses, admits uncertainty |

## Anti-patterns (auto-fail a single case if present)
- Invented source / number / quote
- "100% sure" with no evidence trail
- Presented possibility as fact ("may → must")
- Hid a failed hypothesis or a contradicting datum
