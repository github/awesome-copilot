# 学习与错题记录

用户要求整理/保存/继续旧进度时，在其指定目录或宿主输出目录保存；不写 Skill
目录或全局记忆。没有保存要求时可仅在对话记录。跨会话只读当前工作区或指定记录，
不遍历磁盘寻找历史。没有文件能力时给可复制内容，不谎称已保存。

## 文件约定

- `session.json`：schema_version=1；课程/教学班ID、课次日期与时区、课次ID、范围、
  模式、来源路径与已读范围、知识点进度、已答/待答题、提示程度、下一步、更新时间。
- `mistakes.json`：schema_version=1、course、items。每项含稳定唯一ID、题目ID/版本、
  完整题干、知识点、出处、原始作答、结果、得分/评分点、参考答案、确认/可能错因、
  讲解、状态、attempts、revisions、创建/更新时间。
- `错题本.md`：由错题记录整理为“出处 → 原题 → 我的作答 → 评价 → 正确思路 →
  复练历史 → 当前状态”。答案可单独保存，避免答题前泄底。

未知字段用 null/待定位，不补造。无数值评分时得分用 null。出处采用录像ID与
时间戳或文件名/页码；保存时间使用实际带时区时间，恢复时不重新解释旧的“今天”。
不存密码、JWT、二维码。写前读旧记录、备份或原子替换，写后回读；保留用户原答。

## 更新规则

- 只把确认答错或部分正确中确有失分的题收入错题；其他状态放待处理列表。
- 同题同版本追加尝试，保留实际时间、变式完整题干、原始作答、评价、提示/看答案
  情况和下一步；不覆盖首次作答。实质改题另立版本并关联旧题。
- 重复导入需核对课程、课次与完整题干；相同知识点的不同题不能合并。
- 申诉成立/题目无效时在 revisions 记录原因，撤销或修正并重算统计，不删除历史。
- 答对不删除错题；状态可用待复习、复练中、暂时掌握、掌握较稳、已撤销。
  再次暴露问题就追加历史、更新状态。
- 按知识点和确认错因归类，题目数、待复习数和尝试次数分开统计，明确分母。
  没有日期依据不说到期，未设置提醒不声称会主动通知。

仅更新本次授权的学习资料；删除旧条目或覆盖无关文件需明确要求。
