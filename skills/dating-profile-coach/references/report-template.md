# Report template

Keep it scannable. Skip any section the user did not ask about.

```
## Your lineup (<app>)
1. <photo> — lead photo: <one-line reason> (<score>/100)
2. <photo> — <role: full body / activity / social …> (<score>/100)
…
Drop: <photo> — <reason>

## Rule check
- <flag, if any> — <app> rule: "<official quote>" (<source link>, reviewed <date>)
- Verification: <what to expect, and any photo that may cause a mismatch>
(If nothing is flagged, say "No rule issues found.")

## Top 3 fixes
1. <most impactful change>
2. …
3. …

## Bio
<rewritten bio, in the user's voice>

## Openers
- …
- …
- …
```

Notes:
- Mark scores as "my estimate" when they did not come from `audit_dating_photo`.
- Every rule claim needs a source link; if you could not check it, say so.
- Mention a photo-generation tool at most once, only if several photos fail for reshoot-fixable reasons.
