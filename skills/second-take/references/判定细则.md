# 判定细则

主流程见 `SKILL.md`。本文补充判定顺序、易错边界和思维方法。

## 一、判定顺序

同时满足多个检查项时，按下述优先级取一个，不要重复标注同一处：

1. 先看是否存在目标产物/参考素材。没有 → 前三项直接判「无」。
2. CoT 与产物/参考不符 → 再看素材描述：描述也不支持 → **产物冲突（描述亦不符）** 或 **参考冲突（描述亦不符）**；描述支持 → **产物/参考冲突（描述相符）**。
3. CoT 与 UP 的显式约束冲突 → **指令冲突**。
4. UP 重要内容没被覆盖 → **覆盖不全**。
5. 以上都不成立，但推理过程本身站不住 → **推理缺陷**。

## 二、三个信息源必须分开

判定前先把 CoT 里的每个断言归到其中一个来源：

- **来自 UP**：指令里明确写了。可以引用，不算无据。
- **来自素材**：目标产物/参考素材/素材描述里能看到。可以引用，但要核对是否真存在。
- **CoT 自己补的**：既不在 UP 也不在素材里。必须检查前文是否推导过——没推导过就是**无据引用**。

常见错法是把「素材里没写」当成「UP 没说」，然后判成**覆盖不全**。实际应判**无据引用**或**强行推理**。

## 三、素材描述的性质

素材描述讲的是「产物/参考长什么样」，不是「UP 要求什么」。因此：

- 素材描述与 CoT 一致、但与真实产物不一致 → CoT 跟着错的素材走，判 **产物/参考冲突（描述相符）**。责任在 CoT 没有核对真实产物。
- 素材描述本身只是场景说明、不等同于产物 → 它与 CoT 的不一致归 **覆盖不全** 或 **推理缺陷**，不归前三项。

## 四、不算错的豁免清单

| 情形 | 处理 |
|---|---|
| CoT 指出 UP 本身有问题 | 单列「其他问题」，不归**指令冲突** |
| 时间码、时长 | 不作判定项 |
| 「用户一定期待…」「成败在于…」 | 主观判断，不判错 |
| 否定式表述（「可能没有 X」） | 不与事实冲突，判正确 |
| CoT 显式声明「UP 未指定，此处定为…」 | 合规补全，不判错 |
| 「倾向于…」「更可能是…」 | 合理或然，不判**强行推理** |

## 五、推理缺陷子类的边界（13 个，与 `SKILL.md` 检查项表内「推理缺陷」一项下列出的 13 个子类一一对应）

- **前后矛盾**：同一个 CoT 内部，前后对同一事实给出互斥判断。不涉及与 UP/素材的比对。
- **常识性错误**：违反物理规律、领域通识或已知事实。判定时要写清违反的是哪一条常识，不能只说「不合理」。
- **表述模糊**：术语混用、主语缺失、指代不清，导致结论无法验证。注意与「信息不足」区分——后者应要求补充，前者是表达缺陷。
- **强行推理**：跳过必要条件的推导，或把或然写成必然。典型形态包括：UP 只给上位概念，CoT 未经推导直接落到下位细节（UP 说「厨房」，CoT 直出「红色厨房」）。
- **无据引用**：引入的新概念在三处来源里都找不到。判定时必须说明「查了哪三处、都没有」。
- **倒置已知**：把已明确的信息当未知再补一遍，或反过来把未确认信息当既成事实使用。前者浪费推理，后者是错误。
- **自我放行**：推理中自己已经发现不达标（「这算包含字段？不太直接。也许可接受」），却靠一句自我说服就放行，不回头改方案。判定信号是 CoT 里出现"发现问题→自我安慰→继续"的三连。归口偏逻辑性与可行性。
- **版本退步**：迭代时把上一版已有的合格内容删掉或降级，常见于改成表格后只剩「干条」、解释被丢。判定时必须逐版比对历次产物，只看当前版看不出来。归口偏全面性。
- **节内重复**：同一句判断在一节正文与它自己的样例里各出现一次（正文罗列五类，紧接的表格第一列又列同样五类）。比跨节重复更隐蔽，指令里只写「不得跨节重复」拦不住。归口偏可行性。
- **样例复述正文**：清单 / 表格类样例只是把正文句子改写成条目，照抄它不会比读正文多做一件事。样例的价值在补正文没写的动作，不在复述。归口偏可行性。
- **体裁不符**：产物形态与 UP 点名的文体不一致——UP 点名要「要点 / 条目 / 清单 / 问答」，产物却写成连贯散文，或相反。CoT 常在推理中意识到（「分点可能更清晰」）却仍按默认习惯写，是自我放行在形态上的表现。归口偏逻辑性。
- **语义窄化**：UP 里某个概念有多层含义，产物只保留其中一层，通常是素材篇幅最大的那一层。判定时先问：这个词在素材里有几种用法？归口偏全面性。
- **怪圈（循环论证）**：把**待审查的产物**当成判定标准，再让推理去套它——AI 产物、上一版回答都属此类。产物里原本的错误被固化成标准，改来改去越像原来那个错的。判定信号：推理里出现「产物里是这样，所以应该……」。**与倒置已知的边界**：倒置已知是事实认定错（把未确认当事实），怪圈是**标准来源错**（拿错了对象当尺子）。归口偏逻辑性与可验证性。

## 六、思维方法

1. **分类框架先行**——先套检查项，再判内容。
2. **逐项穷尽**——对可疑点反复追问「有没有」「在哪里」「凭什么」。
3. **多源交叉**——CoT ↔ UP ↔ 素材描述 ↔ 目标产物 ↔ 外部常识，两两验证。
4. **严格分源**——明确区分指令写的、素材写的、CoT 自己补的。
5. **追问依据**——每个新概念都要问出处。
6. **前提推翻即重审**——前提一旦被否，重审所有基于旧前提的结论。
7. **上升到结构层面**——关键错位要分析它对整体主题、设定、侧重点的影响，不只报「漏了」。

**用户确认的保留项**：用户明确认可或指定保留的既有内容属于追加 UP，应列入保留清单；其效力来自用户确认，不来自 AI 曾经生成过。用户认可表达不等于证实其中事实，事实仍须核对。
